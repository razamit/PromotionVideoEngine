# Sound effect sources

Every file in this folder is generated by `scripts/make_sfx.py` from
oscillators, filtered noise and envelopes. No samples, recordings or
third-party packs are involved, so the project owns them outright and no
licence applies. Rerun the script to rebuild them; the seeds are fixed, so
the output is identical each time.

```bash
~/.cache/cartoon-shorts/venv-sfx/bin/python scripts/make_sfx.py
```

All files: 48 kHz, mono, 16-bit PCM, peak -6 dBFS.
